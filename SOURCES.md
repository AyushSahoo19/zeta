# ZETA catalogue sources

The catalogue is an editorial learning sequence, not a demand ranking. Domain roadmaps, projects, responsibilities and typical qualification routes are authored guidance. Level labels indicate a suggested order rather than an official publisher difficulty classification. Employer education and experience requirements differ; portfolios and equivalent practical experience are included as possible routes.

## India compensation

[Talpro India IT Salary Guide 2026](https://talproindia.com/salary-guide/), accessed 14 October 2026. The source labels its table Q1 2026 and describes permanent-role annual CTC bands for junior professionals with 0–3 years of experience. This app displays only selected junior numerical bands. AI Engineer and ML Engineer use the combined AI/ML Engineer benchmark; Full-Stack Engineer uses React + Node. UI/UX Engineer and other named benchmarks use corresponding source rows. These are indicative source benchmarks, not guaranteed salaries or live job offers. Specialist roles without a matching verified benchmark display “Varies by employer”.

## Learning resources

All catalogue resources link to official documentation, official educational material or maintainers' tutorials. Every domain includes beginner, intermediate and advanced links. Some interdisciplinary domains share foundational documentation; their specific milestones and projects define the intended application. Resource hosts include MDN/Mozilla, Harvard CS50, MIT OpenCourseWare, scikit-learn, PyTorch, ROS, QuantConnect, pandas, Ethereum/Solidity, OWASP, LLVM/MLIR, Android, Hugging Face, OpenCV, MLflow, Python, TypeScript, React, Node.js, Next.js, Vue, Angular, Java, Spring, Go, Rust, Microsoft Learn, PHP, Ruby/Rails, Kotlin, Swift/Apple, Flutter, React Native, PostgreSQL, MongoDB, Redis, Apache Spark/Kafka/Airflow, dbt, AWS, Google Cloud, Docker, Kubernetes, HashiCorp, Git, Linux kernel documentation, Google SRE, OpenTelemetry, Playwright, Grafana k6, FastAPI, GraphQL, Arduino, Zephyr, Unity, Blender, W3C, Scrum Guides, GOV.UK Service Manual, Python Cryptography, IBM Quantum, CRAN/R, SciPy, Raft and Elastic.

The precise per-domain URLs are stored in `data.js` and are shown in the app. Primary entrypoints verified by browsing include [MDN learning](https://developer.mozilla.org/en-US/docs/Learn_web_development), [PyTorch tutorials](https://docs.pytorch.org/tutorials/), [Solidity documentation](https://docs.soliditylang.org/en/latest/), [Kubernetes tutorials](https://kubernetes.io/docs/tutorials/), [MLIR tutorials](https://mlir.llvm.org/docs/Tutorials/), [Android training](https://developer.android.com/courses), [OWASP WSTG](https://owasp.org/www-project-web-security-testing-guide/), [Hugging Face learning](https://huggingface.co/learn), [PostgreSQL tutorial](https://www.postgresql.org/docs/current/tutorial.html), [Python tutorial](https://docs.python.org/3/tutorial/), [AWS documentation](https://docs.aws.amazon.com/), and [Azure learning](https://learn.microsoft.com/en-us/training/azure/). Links require internet; app-generated study planners can be downloaded for offline use.

A concurrent HTTP smoke check covered all 215 unique resource URLs on 14 October 2026. Six obsolete documentation paths were replaced with working canonical pages. OpenCV's three documentation links returned HTTP 403 to automated requests, so the smoke check could not confirm their accessibility; they use the official documented tutorial paths. The remaining resource URLs returned successful HTTP responses after corrections. HTTP availability does not certify a complete curriculum or imply that every resource is free of prerequisites.
