# ZETA course academy sources

These are 29 ZETA-authored learning packages, not official paid-platform courses, degrees or certifications. Each package combines the existing domain curriculum with five modules: foundation, application, a reference-repository lab, advanced work and a capstone. Goals and checkpoints are authored study guidance. Estimated hours are editorial planning estimates and vary with prior knowledge and project scope; they are not publisher-stated course durations.

Core resources come from the official domain references documented in `SOURCES.md` and `LEARNING-SOURCES.md`. Matching real PDFs are included only where a relevant verified text exists. A course without a matching external PDF retains its official documentation route; generated study planners are separate and must not be presented as textbooks.

The first eight domain courses retain the previously verified YouTube references. Some videos offer broad introductory context rather than the complete course syllabus, including the economic-mechanisms reference in Quant Research Lab. Other packages use explicitly labelled YouTube discovery searches, without claiming that search results are saved or verified individual videos. Coursera and Udemy discovery routes remain available through the domain resource collection.

## Reference repositories

Module repository links point to recognized project maintainers' GitHub repositories, not invented course repositories. The reference lab explicitly asks learners to choose a relevant example, interface or test rather than requiring a beginner to understand or run an entire production codebase. Repository availability and project identity are checked against primary GitHub pages; a successful response does not imply that a repository is actively maintained or that running arbitrary code is necessary.

[Talpro India IT Salary Guide 2026](https://talproindia.com/salary-guide/), checked 14 October 2026, supplies role-family context for AI/ML, React + Node full-stack, DevOps/platform, data engineering and cloud roles. The named core abilities are editorial learning selections mapped to those role families, not a verified or live ranking of individual skills. No price, employment guarantee or qualification claim is inferred from that source.
