# ZETA learning paths

Each of the 102 domains has an authored beginner, intermediate, advanced and capstone sequence. Topics derive from the existing domain-specific curriculum; exercises and checkpoints connect those topics to the domain's project and explanatory learning material. The three official documentation links remain the primary followable learning route. Difficulty labels are editorial sequencing, not claims about publisher-assigned course levels.

Resource labels name the publisher's actual material rather than implying every page covers a complete milestone. A targeted curriculum review replaced mismatched first-domain links with [Scikit-learn model persistence](https://scikit-learn.org/stable/model_persistence.html), [PyTorch distributed data parallel training](https://docs.pytorch.org/tutorials/intermediate/ddp_tutorial.html), [MIT distributed systems](https://pdos.csail.mit.edu/6.824/) and [MLIR pass infrastructure](https://mlir.llvm.org/docs/PassManagement/). Full-stack stages link to [FastAPI service development](https://fastapi.tiangolo.com/tutorial/), [deployment](https://fastapi.tiangolo.com/deployment/) and [authentication](https://fastapi.tiangolo.com/tutorial/security/). These primary publisher pages were verified during the review.

YouTube, Coursera and Udemy links labelled **Find videos** or **Find courses** open platform search pages for the named domain. They are discovery links, not verified individual courses, saved videos, enrolments or recommendations based on price or ratings. Their beginner label indicates a starting discovery step, not the difficulty of every returned result. Platform results can change and some courses require enrolment.

Direct external PDFs are learning texts or standards; they require internet to open and are distinct from the app-generated offline study planner. Source verification details are added alongside the specific PDF collection below.

## Direct PDF collection

Verified on 14 October 2026 using the original author, institution or publisher host. Resources are mapped to specific relevant domain IDs, rather than assigning an unrelated PDF to every domain. The collection includes a matching text or standard in each of the ten catalogue categories; every domain also retains its own generated study planner.

- [Dive into Deep Learning](https://d2l.ai/d2l-en.pdf): neural-model study for selected AI domains. The [official textbook site](https://d2l.ai/) confirms the title and subject; the direct PDF returned HTTP 200 with PDF content.
- [Think Python, second edition](https://greenteapress.com/thinkpython2/thinkpython2.pdf): Python fundamentals from Green Tea Press. This is explicitly the second edition, not a claim that it is the newest edition.
- [Eloquent JavaScript](https://eloquentjavascript.net/Eloquent_JavaScript.pdf): language and web foundations for JavaScript-based application paths. For TypeScript and framework paths this is supplemental JavaScript foundation material, not a dedicated framework textbook.
- [OSTEP processes chapter](https://pages.cs.wisc.edu/~remzi/OSTEP/cpu-intro.pdf): computer-science and Linux process fundamentals from the University of Wisconsin authors' [official chapter index](https://pages.cs.wisc.edu/~remzi/OSTEP/). This is a free individual chapter, not the paid bundled full-book PDF.
- [Modern Robotics](https://hades.mech.northwestern.edu/images/7/7f/MR.pdf): robotics mechanics, planning and control on Northwestern's institutional host.
- [Convex Optimization](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf): advanced mathematical optimization for mathematics, scientific computing and portfolio-optimization study. This is not a complete trading or finance course.
- [NIST Cybersecurity Framework 2.0](https://nvlpubs.nist.gov/nistpubs/CSWP/NIST.CSWP.29.pdf): security risk-management guidance. It supplements practical security tutorials rather than teaching every technical testing method.
- [AWS Well-Architected Framework](https://docs.aws.amazon.com/pdfs/wellarchitected/latest/framework/wellarchitected-framework.pdf): cloud architecture review material for AWS and related reliability/operations study. The [official HTML page](https://docs.aws.amazon.com/wellarchitected/latest/framework/welcome.html) identifies the framework; the PDF returned HTTP 200 with PDF content.
- [The Scrum Guide, 2020](https://scrumguides.org/docs/scrumguide/v2020/2020-Scrum-Guide-US.pdf): the official framework guide for Agile delivery and product collaboration.
- [Caltech quantum information notes, chapter 2](https://www.preskill.caltech.edu/ph219/chap2_15.pdf): quantum-state foundations for quantum-computing study.
